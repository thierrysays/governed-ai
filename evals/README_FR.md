# Évaluation

Contenu attendu : jeux d'évaluation versionnés, scénarios de red teaming, seuils d'arrêt, rapports.

Règle : aucune valeur de seuil n'est fixée dans ce dépôt sans évaluation de risque du cas d'usage (voir `docs/open-questions_FR.md`). Les jeux sont synthétiques. Toute évolution de modèle, de prompt ou de politique déclenche une évaluation de régression en CI.
